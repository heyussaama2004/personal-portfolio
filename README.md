# Ussama Portfolio

Production portfolio with a server-rendered landing page and an interactive Developer OS.

## Commands

- `npm run dev` — local server
- `npm run lint` / `npm run typecheck` — static checks
- `npm test` — Vitest unit tests
- `npm run e2e` — Playwright end-to-end tests
- `npm run build` — production build

See `docs/CONTENT-GUIDE.md` to update personal data and content without editing components.
