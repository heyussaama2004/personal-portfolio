# Easter Eggs

Harmless terminal-only easter eggs, intentionally absent from `help`:

| Command  | Behavior                                           |
| -------- | -------------------------------------------------- |
| `sudo`   | Playful permission-denied message                  |
| `whoami` | Prints configured owner name                       |
| `matrix` | Short matrix-style output; respects reduced motion |
| `coffee` | Short coffee message                               |

Implemented in the terminal command registry/parser. No tracking, no external calls, no hidden data collection.
