# Deployment

Target: Vercel free tier.

1. Import the repository into Vercel.
2. Set `NEXT_PUBLIC_SITE_URL` to the deployment or custom domain URL.
3. Leave contact variables empty until a delivery provider is configured.
4. Add a custom domain in Vercel and update `NEXT_PUBLIC_SITE_URL` to the final URL.

No database or paid service is required.
